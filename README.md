# Dumpster Cookbook 🗑️📖


## Description
The Dumpster Cookbook is a community-driven project focused on sustainability, urban foraging, and reducing food waste. This repository contains recipes, techniques for safely salvaging ingredients, preserving food (canning, drying), and creative ways to use "imperfect" or rescued produce.

## Features
* **Salvage Guides:** Best practices for sourcing ingredients responsibly.
* **Recipes:** Creative dishes designed to use ingredients commonly found or rescued.
* **Preservation Techniques:** How to make ingredients last longer.
* **Sustainability Tips:** Reducing household waste.
